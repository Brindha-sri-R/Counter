# 🔢 Counter Application

A simple and interactive counter application developed using HTML, CSS, and JavaScript.  
This project allows users to increase, decrease, and reset the counter value dynamically using button controls.

## ✨ Features

- Increase counter value ➕
- Decrease counter value ➖
- Reset functionality 🔄
- Real-time value updates ⚡
- Responsive and clean UI 🎨
- Beginner-friendly JavaScript project 💻

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
